# 2026-09-15 即時膝蓋校準修正

本機工程修正版；沿用 42 類 Transformer v12。真人使用驗收待完成，合成測試不代表實際辨識準確率。

## 變更

- 分離單幀動作速度與回位穩定速度。回位使用最多約 160 ms 的真實觀察窗口，計算位置變動範圍；不把往返動作當成零位移，不補造影格。
- 手部左右標籤在切段專用副本中，以姿態手腕位置配對；同一隻手不能重複計成雙手。分類模型的 handedness、219 維特徵與模型權重不變。
- 手部／姿態追蹤來源切換時保留物理手腕軌跡。手指曾有有效觀察仍計入動作，不能因中間漏測就整個排除。
- 回位判定可使用可信手腕或掌骨中心；坐姿下增加有下半身高度限制的膝蓋鄰域，避免只靠投影後的大腿長度。
- 仍要求可信軀幹、兩個不同手腕、可見雙膝，並持續保持才能建立新基準；胸前停頓、缺資料、逾時不視為正常結束。
- 診斷改為獨立欄位，每次回應都即時更新；顯示實際使用的穩定速度／門檻、阻擋原因、保持進度。未校準顯示「未建立基準」，不再顯示含糊的「算不出來」。
- 模式切換後忽略過期的自動辨識回應及錯誤，避免手動介面又被蓋回自動狀態。

## 第三輪：膝蓋邊界抖動與較長手語

使用者回報「我肚子餓」「我聽不懂」也會逾時。本輪針對共用切段規則修正，沒有以句子名稱建立例外，也沒有重訓模型。

### 根據與限制

- 現有 09:44:05 UTC 啟動的純量紀錄，第二個真人串流前 90 秒出現 12 次首次校準重置，其中 11 次伴隨膝蓋區判定失敗；有一次結束確認在穩定動作分數 0.113 時被幾何判定打斷。有效關節不代表座標完全準確，也不能據此斷定使用者手真的離開。
- 原本 Web 設定的 5 秒上限，會直接排除 6–8 秒才完成回位的動作。新增測試先重現此問題與坐姿邊界微小跳動造成的校準失敗。
- 紀錄沒有句子標記、原始座標或新加入的距離裕量，不能對兩句各自歸因，亦不能聲稱已用舊紀錄完整回放新幾何規則。

### 修正

- 嚴格膝蓋區內的可信雙手先建立候選位置；之後在區域邊界小幅跳動時，允許最多 0.08 個肩寬的退出帶，但雙手腕都必須保持在原位置的 0.10 個肩寬內。使用相對身體的座標，不能隨著移動的手一路漂移。
- 區域外不能自行建立候選；關節失效、影格中斷、人物明显移位會清除候選。手真正離開或停在胸前／腹部的負例仍須拒絕回位。上述容差是候選工程界限，不是已驗證通用於所有真人的參數。
- 只有穩定區域進入才重新啟動動作濾波，不因原始布林值每次翻轉而反覆清空暖機進度。
- Web 共用片段上限由 5 秒改為 10 秒，適用全部類別；原有期限前回位確認的有限寬限保留。逾時仍不送辨識，不能靠期限後重新確認補救。
- 畫面即時顯示本句經過時間／實際上限；逾時提示使用伺服器設定的秒數。未降低 UI 更新頻率。
- 本機私人純量紀錄增加原始／穩定區域旗標、距離裕量及片段時間，不記錄影像或原始骨架陣列。
