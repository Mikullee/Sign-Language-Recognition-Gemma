# Knee42 v13.1 Runnable Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish an immutable Knee42 v13.1 patch whose source-runtime and Windows artifacts install from a clean directory, run the 42-class Knee42 entry, fail closed on tampering, and carry reproducible verification evidence.

**Architecture:** A tracked release specification drives one deterministic allowlist staging builder. Runtime source, complete pinned assets, root/model integrity manifests, trigger provenance, golden contract, locks, and licenses are staged once and consumed by both the Python launcher and PyInstaller onedir build. Runtime behavior is separated into clock, orientation/handedness, integrity/startup, and trigger-evaluation units so each change can be test-driven independently.

**Tech Stack:** Python 3.10, unittest, PyTorch 2.13 CPU, MediaPipe 0.10.14, OpenCV 4.11, NumPy 1.26, PowerShell/cmd launchers, PyInstaller 6.21, deterministic ZIP/SHA-256 JSON manifests.
